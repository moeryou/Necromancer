# 《亡灵工坊》核心玩法与游戏乐趣说明

> 文档版本：当前可玩原型说明
> 整理日期：2026年10月12日
> 本文以已实现机制为基础描述玩法，不把设计愿景或待完善功能当作现成功能。

## 一、一句话介绍

《亡灵工坊》是一款以万圣节喜剧和可爱亡灵为主题的单机策略游戏。玩家经营一座墓园营地，通过建筑布局、资源运输和自动加工，把普通骷髅组织成不同装备的部队，抵挡逐波来袭的敌人，最终击败南瓜王。

它的重点不是手速，也不是逐个控制士兵，而是：**把营地安排好，让它自己高效地运转起来。**

## 二、玩家的身份与目标

玩家扮演亡灵营地的管理者。农夫会自行采集和送货，兵营会自动补充士兵，工坊会给途经的部队加工装备，士兵出城后自行选择敌人并交战。

玩家负责决定：

- 有限空间里，哪些地方用于生产，哪些地方用于加工，哪些地方必须留作通道。
- 新增资金先投入经济、部队加工，还是固定防御。
- 哪些路线优先让士兵接触盾牌、弓箭、重甲或坐骑工序。
- 当前应该依墙驻守，还是向外推进。
- 发现布局不合理时，是否值得拆除重建。

本局的直接目标是守住墓墙，完成三轮普通敌军波次，并在最终战击败南瓜王。墓墙生命归零则失败；士兵损失本身不等于失败，只要生产仍在运转，就有补员机会。

## 三、核心玩法循环

**采集并运输资源 → 获得资金 → 建造和调整营地 → 自动产兵与加工 → 出城交战 → 观察结果、修正布局 → 迎接更强的敌人。**

### 1. 让经济先运转

亡灵农夫会寻找有库存、可到达且有空闲作业位的枯木林和幽灵石。采集完成后，农夫必须把货物运到可到达的仓库附近，卸货后才会增加资金。

这让仓库的价值不只是“存在”，而是“放得合适”。仓库越贴近常用运输路线，农夫越少空跑，单位时间内越容易完成更多趟运输。没有可达仓库时，农夫会保留货物等待，资源不会自动到账。

两种资源最终都折算进同一个资金余额，当前并没有独立的木材、矿石或绿液库存。资源储量有限，枯竭后会释放原来的地块，为后续布局腾出空间。

### 2. 把布局变成装备方案

普通骷髅兵不是通过菜单逐个购买装备，而是在自动行军时接触工坊的相邻地块，获得对应加工。

因此，建筑位置不仅决定哪里不能走，也决定士兵在哪里可能获得装备。玩家通过安排工坊接触面和可通行路线，间接塑造部队配置。

当前加工包括：

| 工序 | 玩家能理解的作用 | 主要取舍 |
|---|---|---|
| 骨盾工坊 | 提高承伤能力 | 降低移速，与弓箭互斥 |
| 骨弓作坊 | 把士兵改为远程单位 | 降低生命，与盾牌互斥 |
| 鬼火锻炉 | 提高生命与生存能力 | 略微降低移速 |
| 幽灵瞄准台 | 提高弓兵伤害 | 必须先持弓，攻击间隔略变长 |
| 骷髅马厩 | 提高速度，提供冲锋收益 | 需要考虑资金和部队配置 |
| 哀嚎号角 | 强化尚未消耗的首次攻击 | 不是持续伤害翻倍 |

同一单位每种工序只会成功获得一次，不会反复经过就无限叠加。盾牌、重甲和坐骑加工额外消耗资金；资金不足或条件不满足时，工序会跳过，后续再次接触仍可尝试。

最明显的路线选择是弓盾互斥：先拿到盾，就不能再拿弓；先拿到弓，也不能再拿盾。瞄准台则需要安排在持弓之后才能发挥作用。

### 3. 用少量部队打出效率

战斗单位同时最多五个，农夫不占这些名额。玩家不能单纯靠无限造兵解决问题，更需要考虑每名士兵的装备、补员路径和战场位置。

兵营自动生产，人口已满或出口没有合适落点时，不会凭空生成新兵。士兵阵亡后，生产设施可以继续补充部队；能否把新兵及时送到前线，取决于营地是否还能顺畅运转。

墓园箭塔提供不占战斗人口的固定火力，但只能建在墓墙上，不能占用墓门。它是另一种资金投入选择，而不是士兵加工的替代品。

### 4. 用全局指令影响战场

部队自动战斗，玩家通过“驻守墓门”和“全力进攻”改变整体倾向。

- **驻守墓门：** 在墙外靠近入口的位置防守，追击较保守。
- **全力进攻：** 向墙外前压，进入视野后自主交战。

指令有资金消耗和冷却，不适合无代价地来回切换。驻守也不是把已经出城的部队召回营地；当前没有逐兵点选移动或手动释放技能。

## 四、道路是营地运行留下的结果

道路不能直接铺设或拆除，而是由己方单位反复通行逐渐形成。农夫往返运输，既创造收入，也会把常用路线踩成更好的道路。

道路改善后，单位移动更快，寻路也会考虑更低的通行成本。高等级道路还有一定防御收益。

这个机制把“经济路线”和“军事路线”联系起来：一条经常被使用的通道，可能逐渐成为整个营地最有效率的主干道。

亡灵巨象是更大、更重的战斗单位，需要双格硬化道路，墓门通行也受到双格空间限制。它表达的是“强力单位需要基础设施支持”的设计思路，而不是放下建筑就一定能无条件出兵。

## 五、一局游戏的节奏

当前开局已经有一套基础营地、五名骷髅兵、八名农夫和资源点，不是从空地开始。右侧首波敌人会预先集结，但在发育阶段不行动、不攻击。

普通波次前有90秒发育时间。玩家可以利用这段时间观察经济和行军，增建工坊、仓库或箭塔，也可以提前迎敌，以剩余发育时间换取一笔奖励。

三个普通波次逐渐增强。击退一波后会获得补给，为修正营地提供资金。第三波结束后直接进入南瓜王最终战，没有额外一轮完整发育期。

最终战击败南瓜王即可胜利，不要求把全部随从都清完。暂停和加速功能允许玩家按自己的节奏思考与观察。

## 六、游戏乐趣来自哪里

### 1. “我摆对了，所以它跑顺了”的成就感

玩家做的是几次建造和调整，但结果会反映在一整套自动系统上：农夫少绕路、资金更快到账、新兵顺利出门、装备组合真正生效。

最重要的奖励不是单次点击，而是看到自己的安排产生持续效果。

### 2. 同一原料，不同成品的组合乐趣

普通骷髅可以因为工序不同而拥有不同的战斗方式。玩家尝试的是“这批兵应该经过哪些设施”，而不是单纯挑选更贵的兵种。

弓盾互斥、持弓前置和加工费用，让组合有选择成本。合理配置比把所有工坊随意堆在一起更有意义。

### 3. 小空间里的规划与取舍

营地里同时存在建筑、资源、运输路线和出兵通道。多放一座设施，可能获得新能力，也可能占掉关键路口。

拆除会返还一半建造费用，允许玩家修正错误，但调整并非完全无成本。游戏鼓励观察、判断和迭代，而不是一次摆完就不再思考。

### 4. 自动系统带来的观察乐趣

农夫忙着送货，骷髅沿路领装备，部队在墓门排队，然后到墙外交战。玩家可以像观察一座小工厂一样，看见自己的营地不断运行。

当资源枯竭、道路形成或士兵损失时，系统状态会变化，原先有效的安排可能需要重新调整。

### 5. 发育时间与战斗压力之间的张力

多等一会儿，经济和道路可能更成熟；提前开波，则能换到即时资金，但前线也会更早承受压力。

五人战斗上限和逐波增强的敌人，让玩家必须同时关注营地效率与墓墙生命。最终Boss把这种压力集中到最后一场战斗。

### 6. 可爱亡灵的黑色幽默

游戏不把墓园当成恐怖场景，而把它变成一座忙碌又滑稽的亡灵工坊：骷髅是流水线上的原料，骨盾和骨马是加工成果，亡灵农夫认真运货，敌人拿着南瓜来捣乱。

幽默来自角色造型与实际行为的反差。深色描边、紫瓦木屋、骨饰、绿色鬼火和南瓜，让生产与防守过程也具有可看的趣味。

## 七、典型体验示例

玩家观察到农夫虽然一直在走，但资金增长很慢。于是先检查运输路线，在更方便卸货的位置增加仓库。

经济改善后，玩家想培养弓兵，却发现士兵先经过骨盾工坊，因弓盾互斥而无法持弓。玩家调整建筑和通路，让部分士兵先接触骨弓作坊，再经过瞄准台。

敌军逼近后，玩家发现前压让近战部队离墓墙太远，于是在指令冷却结束后改为驻守，并考虑用剩余资金增加墙上箭塔。

这段过程体现了游戏的主要思考方式：**观察真实运行 → 找到瓶颈 → 做有成本的调整 → 用下一次运输或战斗验证。**

这只是可能发生的决策过程，不是保证获胜的固定攻略。

## 八、当前版本的边界

为避免将设计目标误写成已经完成的功能，当前需要明确：

- 已实现的是道路升级和士兵加工，没有建筑升级、科技树或永久养成。
- 当前是单机固定参考布局，不是多人协作、随机地图或无限生存模式。
- 经济使用统一资金，没有独立木材、矿石和绿液账本。
- 玩家主要控制布局和全局指令，没有逐兵操作、路线绘制或手动技能。
- 初始营地已经有基础设施，不是从零开始的建造教程。
- 巨象的道路要求已经存在，但当前墓门硬化校验与踩踏区域有衔接限制，不能承诺常规开局养路后巨象就能顺利出城。这属于待修复的实现问题，不应当作为幽默卖点。

## 九、后续可扩展方向（尚未实现）

1. **让规划更容易理解：** 显示运输瓶颈、加工触发区域和单位已获得的装备，帮助玩家理解布局的结果。
2. **让组合更值得尝试：** 在现有弓、盾、重甲、坐骑体系上增加可辨认的战术差异，而不是仅增加数值。
3. **让每局变化更多：** 引入不同资源分布、敌军组合或场景条件，减少固定布局带来的重复感。
4. **让喜剧反馈更丰富：** 增加加工、搬运和出兵时的短动作、表情与音效，但不影响关键战斗信息的辨识。

## 十、核心体验总结

《亡灵工坊》的核心乐趣可以概括为：

**用建筑安排流程，用流程塑造部队，再看自己经营的亡灵营地自动运转、顶住压力。**

玩家是营地的规划者，而不是每个士兵的驾驶员。游戏要让“摆放、观察、调整”的过程，既有策略上的成就感，也有可爱亡灵忙碌生活的喜剧趣味。
