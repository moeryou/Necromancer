# 梦想成为亡灵大师：UI 设计方向 v0.1

日期：2026-10-12。基于 Demo GDD v0.1 与用户提供的墓园战场图。以下为三种视觉概念方向，不是已实现的游戏界面。

## 共用规则

- 可爱欧美卡通、赛璐璐平涂、柔和低饱和配色；深紫或可可色轮廓线，简洁单层阴影。
- 沿用墓园与野外的分区、围栏缺口和固定中央主角。主角与入口之间的主要战斗视野保持开放。
- 顶部突出唯一的“魔力／护罩”条；不添加第二条生命条。显示自然恢复速率。
- 保留枯骨、锻骨、波次、倒计时、暂停、五类建筑与范围诅咒操作。
- 建造时局部显示网格、占地、绕行预览；堵死路线使用橙色警告，仍允许建造。
- 建筑受击后显示血条。资源不足、占地非法和堵路须使用不同反馈，不只依赖颜色。
- 概念图用相同资源与波次状态比较外观，不作为数值平衡或玩法已运行的证据。

## A：幽灵糖果

效果图：[A_幽灵糖果.png](ui-concepts/A_幽灵糖果.png)

**气质：最可爱、最容易理解，偏轻松塔防。**

淡紫托盘、奶油色卡片、薄荷色选中状态、珊瑚色警告，圆润面板搭配幽灵和骨头小装饰。资源位于左上，魔力护罩居中，波次位于右上；底部五张建筑卡，右下为独立诅咒按钮。

建议色板：淡紫 `#B8A3CD`、奶油 `#F5E8D5`、薄荷 `#A8D8C2`、深紫文字 `#4C3B61`、珊瑚警告 `#D98579`。

优势：信息扫读快，图标和交互状态直观，适合作为首个 Demo 的默认方向。

制作注意：限制底部卡片高度和装饰亮度；选中光边不持续大面积发光；实际地图布局须预留底栏安全区，不能让底栏下方建筑失去可选性。

## B：墓园手账

效果图：[B_墓园手账.png](ui-concepts/B_墓园手账.png)

**气质：法师随身魔法书，偏叙事与经营。**

燕麦色纸页、葡萄紫书封、鼠尾草色书签、南瓜色标记。底部以浅矮展开魔法书承载建筑卡；资源使用纸标签，波次使用折页签；诅咒表现为魔法印章按钮。

建议色板：纸页 `#F3E4C8`、葡萄紫 `#80668E`、鼠尾草 `#A9BC9B`、南瓜 `#D9A075`、可可文字 `#594846`。

优势：与亡灵法师研究墓园、复活军队的身份联系更强，可延伸到教程、建筑详情、升级和剧情弹窗。

制作注意：避免旧纸纹理影响文字清晰度，书本不能占据半个屏幕；按钮仍保留清楚的可点击轮廓，不把操作藏在插画内。

## C：骨木营地

效果图：[C_骨木营地.png](ui-concepts/C_骨木营地.png)

**气质：骨饰与木牌组成的营地工具，偏战术经营。**

浅紫石牌、骨白扣件、鼠尾草木板与灰桃色强调。建筑入口集中在左侧纵向工具栏；底部只出现当前建筑的简短操作板；魔力条保持顶部中央，诅咒保持右下。

建议色板：浅紫石 `#9C8DAA`、骨白 `#EEE3CA`、灰绿木板 `#A5B6A0`、灰桃 `#CCA08A`、深紫文字 `#4B4058`。

优势：可将底部空间更多地还给战场，面板材质与墓园设施协调，适合强调建筑布局和即时防守。

制作注意：左侧工具栏仍会遮挡后方经营区，需预留安全区或支持收起；不要做成厚重恐怖墓碑，纵向按钮需满足触屏操作。

## 选择建议

| 方向 | 主要特色 | 更适合 |
|---|---|---|
| A 幽灵糖果 | 直观、轻松、按钮清楚 | 第一版可玩 Demo，优先考虑 |
| B 墓园手账 | 故事与法师身份强 | 希望整体更有角色个性与经营感 |
| C 骨木营地 | 与场景融合，操作集中在侧边 | 希望突出战术布局与营地设施 |

建议先以 A 的信息布局推进 Demo；若更重视故事特色，可选 B。确定方向后统一所有组件的轮廓、颜色与材质，不把三套面板直接混在同一屏幕。

## 后续细化标准

选定一版后，补齐正常战斗、建筑选中、放置合法／非法／堵路、低魔力警报、生产队列、暂停与胜负弹窗。所有按钮核对中文名称和资源图标；文字由真实 UI 排版，避免把生成图上的文字直接当生产素材。

生成方式：内置 imagegen。完整提示词见同目录 `ui-concepts/生成提示词.md`。概念图保存为文档附件，不替换运行时地图或游戏资源。
