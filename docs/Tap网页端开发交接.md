# Tap 网页端开发交接

日期：2026-10-12。

## 当前状态

本地已整理 Demo GDD、三种 UI 方案、地图与资产尺寸说明，以及现有角色、建筑、资源与护罩素材。玩法代码尚未按 GDD 实现，`scripts/main.lua` 保持原有空玩法基线。

## 阅读顺序与冲突处理

1. `梦想成为亡灵大师_Demo_GDD_v0.1.md`：当前玩法与验收的主要依据。
2. `地图与资产尺寸规范.md`：沿用 16×12 格、建筑底座与角色显示尺度。其旧“中央主通道禁止建造”规则已被新版 GDD 覆盖；旧矿石／金属建筑概念不属于本版资源系统。
3. `UI设计方向_v0.1.md` 与 `ui-concepts/`：三版方向对比；用户尚未选定，A 仅为推荐。

用户后续明确的修改高于上述文件。GDD 中新增战斗数值为调试初值，不能当作已通过实机平衡验证的参数。

## 必须保留的核心玩法

- 横屏俯视单个连续地图，主角固定在画面中央附近；人类从右侧野外，经围栏缺口入侵。
- 当前魔力就是当前护罩耐久，初始 500、自然恢复 10／秒。消费后至少剩 1 点；敌人伤害使魔力归零立即失败。
- 建筑允许改变路线、甚至完全堵死路线。有开放路线时敌人绕行；无路时选择可拆路线，攻击首个阻挡建筑；拆开后重新追击主角。
- 建筑脆弱，受击后显示血量。地面单位拥挤不应被误判成建筑封路。
- 幽魂采集魔力或枯骨，搬运回主角交付；初始赠送一只，避免开局资源软锁。
- Demo 为五种可建建筑、三种我方单位、五种敌人、六波入侵；锻骨用于塔升级，魔骨晶留作后续扩展。

## 实现顺序

先完成路线、堵路拆建筑与重新寻路原型，再接入经济、军队和基础战斗，最后添加六波、教程、UI 与结局。逐项使用 GDD 第 13 节验收，不要先扩展终极资源、更多兵种或局外系统。

## 素材使用

正式地图入口为 `assets/image/battlefield_main.png`；`battlefield_main_backup_20261012.png` 是历史备份。

现有图片包含早期方向与多个版本，不能把所有建筑都自动纳入 Demo。优先参考 GDD 的名称、作用和占地，选择匹配的素材；带 `_alpha_` 的文件名表示透明背景版本候选，仍需检查实际图片。

UI 概念图只作为视觉与布局参考，不能整张覆盖战场代替界面。部分生成文字及锻骨图标需要校准；场景中的单位数量、路线与位置不作为玩法验证证据。

本地 Maker 身份、访问凭据与运行状态不属于交接内容，不上传或要求网页端复用。
