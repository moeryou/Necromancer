# 梦想成为亡灵大师 — Demo GDD

- 版本：v0.1
- 日期：2026-10-12
- 定位：单地图、单局制、横屏 2D 基地经营与动态路线塔防 Demo
- 目标时长：首次试玩约 10—12 分钟，不含阅读开场和暂停时间
- 状态：设计基线，尚未经过实机平衡验证

## 1. 设计摘要与范围

玩家扮演追随山德鲁的流浪亡灵法师，在埋藏着贞德秘密的墓园中建立亡灵基地。人类从地图右侧进入，穿过围栏缺口，寻找路线攻击中央的亡灵法师。玩家通过采集、生产、建筑布局和范围诅咒抵御六波入侵。

**核心体验：花费魔力发展基地，同时承担护罩变弱的风险；用建筑改变敌人的路线，但无法依靠永久堵路获得安全。**

### 1.1 三项设计支柱

1. **魔力就是生命。** 建筑、召唤和技能共享魔力余额，发展与保命始终存在取舍。
2. **布局就是战术。** 建筑可以迫使敌人绕行，将其引入火力区；彻底封路后，敌人会拆毁阻挡建筑。
3. **亡灵军队提供真正的防线。** 建筑脆弱，骷髅步兵负责拦截，弓手与骨箭塔负责输出，主角诅咒负责处理危机。

### 1.2 Demo 内容边界

- 用户已给定的价格、初始魔力、自然恢复、资源点储量和加工配方，全部保留。

## 2. 剧情与表达

### 2.1 背景

流浪亡灵法师追随传奇法师山德鲁，梦想成为历史上最出色的亡灵大师。他发现一块灵脉异常充沛的人类墓园，地下似乎埋藏着被诅咒的圣女贞德。

墓园距离人类城镇很近，占领它将招来巡逻队、城镇守卫和教会的追查。法师明知危险，却认为因为恐惧而放弃变强才是弱者的选择。

Demo 中击败的是逐步升级的地方围剿与小规模教会审判队。真正的大规模审判教团仍是未来威胁，保留故事后续发展的空间。

### 2.2 开场文案草案

> 我追随山德鲁，只为有一天成为最出色的亡灵法师。
>
> 这座墓园下面，沉睡着惊人的死灵魔力……还有一个名字：贞德。
>
> 可惜，人类城市就在附近。巡逻队会来，教会也会来。
>
> 因为害怕强敌，就放弃变强？那是弱者的思维。
>
> 我一定要成为亡灵大师！
>
> 被远比自己强大的敌人包围，就一定会输吗？
>
> 会、会赢的！

开场控制在约 30 秒，可一键跳过。重要设定在教程中再次简短提示，不要求玩家读完才能操作。

## 3. 地图与空间规则

### 3.1 视角与功能分区

地图采用横屏俯视 2D，固定相机、单个连续战场。背景图左侧约四分之三是紫褐色墓园，右侧约四分之一是明亮野外，两者之间由纵向围栏分隔，围栏中央留有缺口。

“左右分区”指功能分区，不使用两个独立视口。角色可在地面平面上上下左右移动，不采用固定横向单线战斗。

```text
左侧墓园后方          地图中央              墓园前沿        缺口       右侧野外
采集／加工／生产  →   亡灵法师与护罩  ←   建筑迷宫与亡灵防线  ←  人类入侵
                      固定核心             可绕行、可破坏
```

### 3.2 网格与主角位置

| 项目 | 规则 |
|---|---|
| 营地网格 | 16 列×12 行，列从左到右、行从上到下 |
| 主角占地 | 第 11—12 列、第 6—7 行，2×2 格；对应参考画面中间附近 |
| 后方经营区 | 第 1—10 列，优先放采集、生产和加工设施 |
| 前沿布局区 | 第 13—16 列及主角上下侧可用空间，承担绕路与拦截功能 |
| 地图围栏 | 固定不可破坏障碍，只有中央缺口通行；禁止建造 |
| 野外 | 敌人出生与集结区域，Demo 不允许玩家建造 |
| 中央通道 | 初始畅通，允许玩家建造并堵路 |

主角不可移动、拆除、重建或出售。其周边保留一圈禁止建造的接敌空间，确保近战敌人有可攻击护罩的落脚点；这圈空间允许单位通行。圈内不得放初始资源点。

围栏缺口、树木边界和外圈装饰以独立通行数据定义，不直接把整张背景图当作碰撞。靠近缺口的营地格允许建造，缺口本身及野外出生区不可建造。

网格吸附用于建筑；单位连续移动，不需要表现为逐格跳动。寻路以格为基础，允许八方向移动，但禁止穿过两个相邻阻挡格之间的对角夹缝。所有 Demo 地面兵种均可通过一格宽通道，大型首领的美术尺寸不额外扩大通行需求。

### 3.3 初始配置

- 魔力：500／500；枯骨：0；锻骨：0。
- 主角：1 名；幽魂：1 只，免费初始单位，默认采集最近的枯骨堆。
- 无初始可生产建筑，教程引导玩家建造骷髅墓穴。
- 魔力晶簇：4 处，每处 200 魔力，总量 800。
- 枯骨堆：8 处，每处 200 枯骨，总量 1600。
- 资源点固定布局：大部分在后方，至少 1 处魔力晶簇和 2 处枯骨堆在主角右侧或上下侧的前沿可用格。
- 开局从围栏缺口到主角周边至少存在两条可通行路线；资源点不应形成初始封路。

资源点在建造层占 1×1 格，禁止重叠建造，但在寻路层视为可通行地面。采集完后移除资源点及其建造占用。此规则避免资源本身形成不可拆除的路障。

## 4. 单局流程与教程

### 4.1 单局结构

开场 → 引导采集与召唤 → 第 1—2 波基础防守 → 第 3 波布局与拆路 → 第 4—5 波锻骨升级与教会压力 → 第 6 波首领战 → 结算与结局。

战斗期间经营持续运行，玩家可以即时建造和召唤。暂停会停止采集、生产、自然恢复、战斗、冷却和波次计时，不允许在暂停时提交建造或技能操作。

### 4.2 教程步骤

| 步骤 | 玩家操作／触发 | 教会的概念 |
|---|---|---|
| 1 | 看见初始幽魂采集枯骨，完成第一次交付 | 资源需要运回主角才入账 |
| 2 | 建造骷髅墓穴 | 花费魔力会同时降低护罩 |
| 3 | 召唤两名骷髅步兵 | 战斗单位自动到前线 |
| 4 | 第一波开始，观察步兵拦截 | 主角固定，敌人会寻找路线接近 |
| 5 | 建造幽魂祭坛，召唤第二只幽魂并指定魔力晶簇 | 主动扩张采集能力 |
| 6 | 建造骨箭塔，查看放置后的路线预览 | 开放路径时敌人绕行 |
| 7 | 第三波前出现封路提示和拆建筑规则说明 | 堵死允许放置，但会招来拆除 |
| 8 | 解锁锻骨坊并升级一座塔 | 资源加工产生明确战力收益 |

首次教程中，第一波须同时满足“开局主动游戏时间达到 90 秒”和“完成两名步兵召唤”才开始；满足后额外给 10 秒预警。不强制玩家真的堵路或牺牲建筑。第二次及以后可跳过教程，第一波按固定 90 秒准备期启动。

引导只标出推荐目标，不长期锁死其他操作。后续波次不能通过不完成教程任务无限推迟。

## 5. 资源与魔力护罩

### 5.1 基础规则

| 资源 | 来源 | 用途与规则 |
|---|---|---|
| 魔力 | 初始 500；自然恢复 10／秒；幽魂采集 | 所有建筑、召唤、技能；当前余额完全等于护罩耐久 |
| 枯骨 | 幽魂采集；人类死亡概率掉落 | 基础建筑、骷髅召唤、加工锻骨 |
| 锻骨 | 锻骨坊每次消耗 10 枯骨，产出 1 锻骨 | 本版用于骨箭塔一级升级 |
| 魔骨晶 | 扩展：100 魔力＋10 锻骨合成 1 个 | 本版不开放生产与消耗入口 |

魔力初始上限为 500，Demo 不开放上限升级。枯骨和锻骨不设仓储上限。魔力支持内部小数累积，界面显示整数；购买资格使用真实余额计算。

### 5.2 护罩与失败判定

1. 没有独立护罩生命条：护罩当前耐久直接读取当前魔力。
2. 自然恢复和魔力交付均不得超过 500 上限。
3. 建造、召唤、升级、技能和加工扣费必须完整支付；扣费后魔力须至少剩余 1 点，否则不允许提交。
4. 敌人命中护罩后扣除对应魔力；结算一次伤害后若魔力≤0，立即失败，不等待下一次恢复。
5. 非致死受击后自然恢复继续有效，不额外设置战斗恢复延迟。
6. 不设置“消耗魔力修复魔力护罩”操作，避免同一资源扣除再恢复的无效循环。

取消尚未完成的生产订单可能返还魔力；返还也受上限约束，超出部分不保留。订单费用不会成为无限储存魔力的隐藏仓库。

### 5.3 幽魂采集与交付

- 幽魂能采集魔力晶簇和枯骨堆，补齐枯骨获取链路。
- 默认寻找最近且未被预约满额的指定类型资源点；玩家可以选中幽魂，再点击资源点改变目标。
- 魔力采集速度：10 点／秒；枯骨采集速度：5 单位／秒；每只最多携带 50 单位，同一次运输只携带一种资源。
- 满载、目标耗尽或手动回收时返回主角周边交付。采出时就扣除资源点储量，交付时才增加玩家资源。
- 初始幽魂默认采骨；祭坛新增幽魂默认采魔力；玩家可自行改派。
- 两只幽魂可同时采集同一资源点，领取时原子扣减剩余量，不能重复获取资源。
- 幽魂被敌人命中立即消散，携带资源丢失；不自动复活。
- 幽魂可以穿过玩家建筑占地，但不能越过地图边界与围栏；这不保护它免受攻击。前沿采集路线仍可能被敌人截断。
- 玩家魔力已满时，持有魔力的幽魂保留未交付部分，在主角周边等待；余额降低后继续交付，不销毁资源，也不继续采集。魔力型幽魂空载且余额已满时等待。
- 指定类型全部采尽后，幽魂返回主角附近待命，显示“资源已采尽”；需要玩家改派，不静默切换资源类型。
- 没有可达采集／交付位置时等待并显示原因；相关建筑变化后重新尝试。

### 5.4 敌人掉落

普通人类死亡时有 50% 概率掉落 5 枯骨；首领必定掉落 30 枯骨。掉落在死亡时直接入账，地面骨屑仅作为视觉反馈，不增加拾取微操。召唤物和建筑被毁不掉落资源。

### 5.5 经济风险与调试重点

自然恢复每分钟提供 600 魔力；全地图魔力晶簇只额外提供 800。因此晶簇定位为前中期的加速资源，采集完后的持续经济依赖自然恢复。Demo 不扩展被动产魔建筑。

平衡时优先验证：玩家是否值得花 200＋50 魔力建立祭坛并召唤额外幽魂；是否能在防线完整时积累资源，而在漏怪后被持续消耗；是否需要主动保留施法魔力。不要在保留原始基准的前提下误把等待视为无限安全——波次持续推进。

## 6. 建筑系统

### 6.1 建造与放置

- 本版所有可建建筑均为 2×2 格，资源点为 1×1 格，主角为 2×2 格。
- 可在有效营地格任意放置，允许切断当前全部敌人路径。封路提示不阻止建造。
- 不得覆盖主角保留区、资源点、已有建筑、围栏、界外或当前地面单位的位置。幽魂所在位置同样禁止突然落建筑。
- 确认放置时一次扣费，底座立即成为寻路障碍；施工中的建筑可以被攻击，从 1 点血量线性增长至完整血量，被摧毁则停止施工、不退款。
- 建造期间不能生产或攻击。完成后启用功能。
- 普通建筑建造时间 3 秒；骨箭塔 2 秒。施工时间不随升级改变。
- 不提供战斗中搬迁、拆除和出售；放置预览可取消，已确认的建筑仅由敌人破坏。局间重开重置布局。
- 选中建筑可以查看数值与操作。放置预览显示预计魔力余额和路径影响。

### 6.2 建筑表

| 建筑 | 建造价格（原始基准） | 血量初值 | 功能 | 解锁 |
|---|---|---:|---|---|
| 幽魂祭坛 | 200 魔力 | 40 | 召唤幽魂，5 秒／只 | 开局 |
| 骷髅墓穴 | 250 魔力＋30 枯骨 | 60 | 召唤骷髅步兵，5 秒／只 | 开局 |
| 骨弓塔巢 | 300 魔力＋50 枯骨 | 45 | 召唤骷髅弓手，6 秒／只 | 第 2 波清场 |
| 骨箭塔 | 200 魔力＋40 枯骨 | 70 | 自动攻击敌人 | 开局 |
| 锻骨坊 | 150 魔力 | 50 | 10 枯骨→1 锻骨，3 秒／次 | 第 3 波清场 |

建筑是脆弱的设施，不是高血量城墙。重装步兵对建筑每次造成 20 点伤害，两名合击应在数秒内摧毁基础建筑。生产设施适合放后方，塔与通道建筑需要亡灵保护。

### 6.3 队列与破坏

- 每个生产建筑同时执行 1 个订单，最多排队 3 个，含正在执行的订单；确认每个订单时预扣完整资源。
- 排队订单可以取消并返还原价；取消当前订单丢失进度。返还魔力按当前上限结算。
- 单位人口在下单时预约，取消或建筑毁坏时释放，避免多个队列超出上限。
- 建筑被毁：当前及排队订单全部丢失、不退款；已完成单位不受影响。
- 建筑被毁后移除寻路占用和建造占用，遗骸装饰不阻路、不阻建。
- 锻骨坊支持单次加工和自动加工开关。自动加工一次扣 10 枯骨；资源不足则等待；只扣当前加工材料，不提前扣未来批次。被毁损失当前加工材料。
- 单位出生时寻找建筑周围最近的合法落脚点。若所有出口都被建筑封死，订单停在完成状态，显示“出口受阻”，不能继续执行下一单，也不能穿墙出生。

### 6.4 骨箭塔与升级

| 项目 | 基础塔 | 一级升级后 |
|---|---:|---:|
| 单次伤害 | 12 | 18 |
| 攻击间隔 | 1 秒 | 1 秒 |
| 射程 | 4 格 | 5 格 |
| 建筑血量上限 | 70 | 70 |
| 升级价格 | — | 100 魔力＋5 锻骨 |

升级耗时 5 秒，期间停止攻击，仍可被攻击且继续阻路；完成不治疗建筑。只允许升一次，升级中毁坏不退款。射程从建筑底座中心计算，攻击判定使用目标实际接地点。

骨箭塔优先攻击射程内最接近主角的敌人，同距离优先攻击正在拆建筑者。射击与命中要有清楚反馈，Demo 建筑不遮挡弹道，固定围栏遮挡射线；不能穿过封闭围栏攻击野外目标。

### 6.5 血量显示

未受损且未选中的建筑不显示血条。第一次受到伤害后立即显示，受损期间持续可见；选中时显示当前／最大血量；满血未选中时隐藏。施工显示进度条，遭攻击时同时显示血条。被毁有短暂破碎、受击音效与“路线已打开”提示。

## 7. 动态寻路与拆建筑规则

### 7.1 基本原则

**存在通向主角的可通行路径时，敌人绕路；不存在时，敌人选择一条拆除路线，攻击沿途阻挡建筑。**

敌人不会因为某栋建筑靠得近就随意拆它，也不会因为直线方向被挡就认定整张地图堵死。

### 7.2 敌人行为优先级

1. 死亡或控制状态先结算。
2. 攻击射程内可见的亡灵战斗单位；幽魂同样在射程内时，优先战斗单位，之后幽魂。
3. 若能在当前位置合法攻击主角，直接攻击护罩，无须先走到近战接敌格。远程敌人可从自己的有效射程发起攻击。
4. 存在到达合法攻击位置的开放路线：沿最短可通行路线推进。
5. 开放路线全部不可达：执行拆路逻辑。

目标必须满足射程和固定地形视线条件；建筑不提供远程遮挡，远程敌人已经能攻击主角时，即使近战路线堵死也不会被迫拆建筑。亡灵近战拦截可以使敌人停下交战，处理完后继续朝主角推进。

### 7.3 拆路目标的选择

当正常路线不可达时，进行一次“允许付出代价穿过玩家建筑”的路线计算：

- 普通地面代价为移动距离。
- 固定围栏和界外始终不可通行，不能作为拆路候选。
- 玩家建筑视为可拆障碍；穿过一栋建筑的代价为预计拆除时间加移动时间，同一建筑不能按占格重复计费。
- 预计拆除时间依据该敌人对建筑的伤害、攻击间隔和当前建筑血量计算，不计其他敌人协助。
- 选择总代价最低的候选路线，并锁定其中遇到的第一栋建筑。
- 敌人移动到该建筑的合法攻击位置后攻击，毁坏后重新执行正常寻路。

若仍然没有任何路线，视为地图通行配置异常，敌人短暂等待并重试；正式地图验收必须消除此情况，不允许停在原地形成永久安全局。

### 7.4 动态更新与稳定性

- 建筑确认放置、被毁，以及其他永久通行变化触发路径更新。
- 封路建筑被毁后，只要出现开放路线，敌人停止无必要的拆除，继续追击主角。
- 玩家新放建筑使另一条路线开放或原路线改变时，相关敌人重新判断，不沿旧路径穿墙。
- 拆除目标锁定到目标被毁、出现开放主角路线、或目标无法再攻击为止；不因其他建筑血量轻微变化每帧切换。
- 战斗单位使用局部避让，不作为建筑级永久硬障碍；同阵营拥挤不能误触发拆建筑。敌人在狭窄通道排队推进，有效攻击位置有限，不能全部重叠在同一点攻击。
- 地面我方单位同样遵守建筑与围栏占用。到不了集结位置时，停在最近可达位置接敌，并显示“前线受阻”，不会攻击自家建筑。

### 7.5 玩家预览与示例

进入建造模式后显示缺口至主角的代表性近战路径；路径不是所有敌人的承诺路线。每次挪动建筑预览都更新结果：

| 状态 | 提示 |
|---|---|
| 可放置，路线仍通 | 绿色占地框；显示绕行路径 |
| 可放置，但堵死 | 橙色占地框；“道路封闭：近战敌人将拆毁阻挡建筑” |
| 占地非法或资源不足 | 红色占地框；显示具体原因，禁止确认 |

示例 A：两栋建筑让中央路线变成向上绕行，敌人绕行，骨箭塔得到更长输出时间。

示例 B：上下绕行口全部封闭，重装步兵选择最容易突破的建筑并拆毁。

示例 C：建筑被毁后形成通路，敌人转向主角；原先的迷宫布局出现缺口，玩家需要用亡灵补线。

不增加专门的廉价墙体，避免建筑迷宫取代经营与军队。后续平衡若发现极长绕路成为必胜解，先调整可用空间、波次压力和火力覆盖，再考虑新增拆路行为；本版不违背“有路就绕”的既定规则。

## 8. 我方单位与战斗

### 8.1 单位初值

距离以地图格为设计尺度，速度为格／秒；它们不是引擎米制参数。开发时应按统一地图尺度转换。

| 单位 | 召唤价格 | 血量 | 伤害 | 攻击间隔 | 射程 | 移速 | 生产时间 |
|---|---|---:|---:|---:|---:|---:|---:|
| 幽魂 | 50 魔力（原定） | 被命中即消散 | 0 | — | — | 3 | 5 秒（原定） |
| 骷髅步兵 | 60 魔力＋10 枯骨 | 100 | 12 | 1 秒 | 0.8 | 1.5 | 5 秒 |
| 骷髅弓手 | 80 魔力＋15 枯骨 | 45 | 10 | 1.2 秒 | 4 | 1.3 | 6 秒 |

人口上限：幽魂 6 只，战斗单位合计 24 名；预约人口计入上限。骨箭塔最多同时存在 4 座；其他同类建筑最多 2 座。用于控制 Demo 屏幕密度与生产爆发，不设置额外人口建筑。

### 8.2 自动行动与集结

- 骷髅步兵召唤后自动向主角右侧前线移动，进入警戒范围后攻击最近敌人。
- 骷髅弓手前往主角右后方的可达位置，在射程内攻击；不直接冲入敌人队列，不实现复杂风筝。
- 生产建筑可点击设置一个集结点，仅允许设在墓园可通行地面；玩家无需逐个微操战斗单位。
- 单位从集结点追敌距离最多 3 格，不主动追进野外；脱离警戒范围后返回。
- 战斗单位死后消失，无复活、无治疗建筑；需要补充召唤。
- 亡灵法师没有免费普通攻击，防守依赖军队、塔和付费技能。

### 8.3 范围诅咒：枯萎之咒

| 参数 | 调试初值 |
|---|---|
| 消耗 | 80 魔力 |
| 冷却 | 20 秒 |
| 施法距离 | 主角周围 6 格 |
| 作用半径 | 2 格 |
| 即时效果 | 对范围内敌人造成 35 伤害 |
| 持续效果 | 移速降低 30%，持续 4 秒 |

点击技能按钮进入选区，点击合法地面确认，右键／取消按钮退出。确认时再次检查余额、距离和冷却；扣费后至少剩 1 魔力。范围预览明确标出覆盖敌人，不误伤我方。首领伤害正常生效，减速只生效 15%；减速不叠加，重复命中刷新持续时间。

## 9. 敌人与波次

### 9.1 敌人初值

| 敌人 | 血量 | 单次伤害 | 攻击间隔 | 射程 | 移速 | 特点 |
|---|---:|---:|---:|---:|---:|---|
| 民兵 | 50 | 8 | 1.2 秒 | 0.8 | 1.1 | 基础近战，建立防守认知 |
| 猎人 | 40 | 8 | 1.5 秒 | 3 | 1.0 | 远程输出，考验前排与诅咒选区 |
| 重装步兵 | 150 | 20 | 1.4 秒 | 0.8 | 0.8 | 高血量，能迅速拆除脆弱建筑 |
| 传教士 | 70 | 6 | 1.5 秒 | 3 | 0.9 | 每 4 秒治疗 3 格内最低生命比例友军 20 血，不治疗自身、不复活 |
| 审判骑士首领 | 650 | 32 | 1.4 秒 | 0.9 | 0.9 | 对骷髅单位伤害×1.5，部分减速抗性 |

传教士治疗与攻击共享行动时机：治疗可用且有受伤友军时优先治疗；施法动作 1 秒，期间不攻击。没有有效治疗目标时按正常敌人规则推进。普通敌人对单位、建筑、护罩使用表中伤害；首领额外亡灵伤害仅作用于骷髅单位，不再次放大建筑或魔力护罩伤害。

### 9.2 六波配置

| 波次 | 剧情阶段 | 组成 | 本波重点 |
|---|---|---|---|
| 1 | 边境巡逻 | 民兵×6 | 两名步兵初次拦截 |
| 2 | 巡逻增援 | 民兵×8、猎人×3 | 增加后排输出，开放骨弓塔巢 |
| 3 | 城镇守卫 | 民兵×8、猎人×3、重装步兵×2 | 验证绕路与封路拆建筑，清场后开放锻骨坊 |
| 4 | 教会先遣 | 民兵×6、猎人×4、重装步兵×4、传教士×1 | 治疗敌人登场，学习用诅咒集中处理 |
| 5 | 围剿升级 | 民兵×8、猎人×5、重装步兵×6、传教士×2 | 补兵、升级塔、保留魔力 |

### 9.3 调度规则

- 第一波使用教程规则或跳过教程后的 90 秒准备期。
- 每波从出生区按固定编组顺序分批出场，间隔约 1.5 秒；第六波首领在本波开始后 25 秒出场。
- 第二波起：下一波开始时间为“上一波开始后 90 秒”与“上一波全部敌人死亡后 25 秒”两者中更晚的时间。
- 若上一波开始后 120 秒仍未清场，下一波强制开始，允许叠波，防止留下一个敌人无限经营；如果已有清场后的休整计划，也不得超过此上限。
- 下一波开始前 10 秒显示入口预警和兵种图标。叠波时界面明确显示多波敌人仍存活。
- 第六波不再触发下一波，必须消灭所有波次残余敌人和首领才能获胜。
- 提供“提前迎战”：只有上一波已清场才可点击，立即进入 10 秒预警，不给予额外资源奖励。

目标时长需通过实机验证，波间时长和编组是首轮调参对象，不把 10—12 分钟当成已经证明的结果。

## 10. 胜负与结算

### 10.1 失败

敌人伤害使当前魔力归零，护罩破碎，主角倒下，立刻冻结游戏过程并进入失败结算。同一模拟时刻若同时满足胜利与护罩归零，失败优先。

失败面板显示到达波次、存活时间、建筑损失、主角承受总伤害，提供“重新挑战”和“返回标题”。提示根据失败前主要问题生成，如“前沿建筑被毁后出现缺口”或“最后一次消费后魔力储备过低”，不直接宣称唯一失败原因。

### 10.2 胜利

第六波全部敌人生成完毕，且场上所有敌人死亡，主角魔力大于零。停止生产、采集与战斗，墓园灵脉亮起，播放结局。

> 墓园终于安静了。
>
> 我听见地底传来一个女人的声音。
>
> “你以为……你唤醒的是谁？”
>
> ——贞德的低语

胜利面板显示总用时、剩余魔力、击杀数、幽魂损失、建筑损失，提供“再来一局”。不在 Demo 中解锁可操作贞德或新增关卡。

- 顶部中央：最大号的“魔力／护罩 当前值／500”，标出“＋10／秒”。魔力≤100 时进入红色警戒，购买预览同时显示消费后余额。

- 战场：建造时显示网格、占地和代表性路径；正常战斗时隐藏格线。

受击反馈要区分“花费魔力”和“敌人造成伤害”：花费在按钮与护罩处显示支出，受击显示冲击与伤害数。两者都更新同一余额，避免玩家误以为还有隐藏生命值。

## 12. 美术与音效需求

### 12.1 视觉原则

沿用参考地图的卡通墓园与秋日野外风格。亡灵以骨白、紫色、幽绿区别于人类的皮革、钢铁和圣光色。主角护罩、敌人入口、资源点和可交互建筑须一眼可辨。

建筑按底座占地缩放，不按图片画布尺寸判断大小；普通单位主体约 1 格高，主角约 1.2 格，首领约 1.4 格。单位显示大小不等于寻路占用。深度排序以接地点为准，避免屋顶和武器错误遮挡角色。

### 12.2 最小资产清单

| 类别 | 必需内容 |
|---|---|
| 地图 | 背景、不可通行边界与围栏数据、缺口数据 |
| 主角 | 待机、施法、失败；魔力护罩正常／低魔力／破碎表现 |
| 我方 | 幽魂采集与运输；步兵和弓手移动、攻击、死亡 |
| 敌人 | 五种敌人移动、攻击、死亡；传教士治疗；首领辨识效果 |
| 建筑 | 五类建筑正常、施工、受击与破坏反馈 |
| 资源 | 魔力晶簇、枯骨堆、枯竭反馈 |
| 特效 | 骨箭、诅咒范围、治疗、圣光受击、资源交付 |
| 音效 | 建造、召唤、资源交付、骨箭、近战、建筑受击与破坏、护罩受击与破碎、波次警报 |
| 音乐 | 一首循环战斗音乐；首领阶段可通过强度变化提示，无须额外整曲 |

## 13. 制作顺序与验收

### 13.1 实现顺序

1. **路线原型：** 地图占用、主角目标、敌人推进、建筑绕行、封路拆除、毁坏后重算。
2. **经济闭环：** 魔力与护罩共用余额、自然恢复、幽魂采骨和采魔、运输交付、墓穴召唤。
3. **基础战斗：** 步兵拦截、弓手、骨箭塔、诅咒、前三波。
4. **进阶与结局：** 锻骨加工、塔升级、治疗敌人、首领、六波调度和结算。
5. **呈现与调试：** 教程、血条、路径预览、受击反馈、经济和难度调整。

先验证动态路线与拆建筑是否成立，再投入完整美术和大量兵种。该规则是本 Demo 的主要差异点，也是最容易产生卡死与利用漏洞的部分。

### 13.2 功能验收案例

| 案例 | 预期结果 |
|---|---|
| 放置建筑挡住直线路径，仍有侧路 | 敌人绕行，不拆建筑 |
| 完全封死主角的近战可达路线 | 敌人选择阻挡建筑，移动到攻击点拆除 |
| 一次封路需拆多栋建筑 | 按路线逐栋拆除，不攻击远处无关建筑 |
| 阻挡建筑被毁后出现通路 | 敌人重新追击主角，不继续乱拆 |
| 在敌人脚下放置建筑 | 禁止确认，不困住或传送单位 |
| 远程敌人已有合法主角射程，但近战路堵死 | 直接攻击护罩，不被迫绕路或拆楼 |
| 对角两格阻挡，仅剩斜角夹缝 | 不穿缝，按真实通行判断 |
| 狭窄通道被单位拥挤占据 | 局部避让／交战，不误判成建筑封路 |
| 生产建筑出口全部封闭 | 显示出口受阻，不穿墙出生 |
| 建筑施工中受攻击并被毁 | 清除施工与占用，不完成生产功能 |
| 建筑有订单时被毁 | 订单与材料丢失，人口预约释放，已出兵仍存活 |
| 魔力购买后将低于 1 | 操作被拒绝，其他资源也不扣除 |
| 敌人致死命中与恢复处于同一时刻 | 致死命中立即失败，不能自然恢复救回 |
| 魔力满时幽魂交付 | 未交付部分保留，不丢失、不超上限 |
| 幽魂满载途中死亡 | 携带资源丢失，不增加库存 |
| 资源点采尽 | 清除占用，空格可建，幽魂继续找同类型资源 |
| 第六波清场但还有前波残留 | 不胜利，消灭所有残余后才结算 |
| 留一个敌人拖延休整 | 达到 120 秒上限后下一波仍会开始 |

### 13.3 体验验证目标

- 首次玩家在第一波前能完成采集、建造和两次召唤，不出现缺少枯骨来源的软锁。
- 玩家能用一句话解释“魔力下降也代表护罩下降”。
- 玩家至少能观察一次明显绕行，并理解完全堵路会导致拆建筑。
- 建筑受击后血量清楚可见；破坏发生后，玩家能识别新出现的路线缺口。
- 不存在靠封路让敌人永远原地不动的获胜方式。
- 治疗敌人与最终首领促使玩家补兵、升级或使用诅咒，而不是只等待自然恢复。
- 通过数轮试玩把单局调整至约 10—12 分钟，并记录失败集中在哪波、哪些建筑无人使用。

以上为目标，交付代码后仍须用运行证据和实际试玩验证，不能仅通过阅读本 GDD 宣称达成。

## 15. 相对初始方案的关键调整

1. 以用户补充的地图为准：主角在画面中央，墓园内允许上下绕行与建筑封路，取消固定单线战斗建议。
2. 初始赠送一只幽魂，允许它采集枯骨，打通从零枯骨到建造墓穴的开局链路。
3. 保留原始资源基准，明确魔力上限与消费保护，统一护罩和失败判定。
4. 把“绕路／拆楼”写成可验收规则，包含远程敌人、动态重算、拥挤与出生出口等边界情形。
5. 将 Demo 收敛到五种建筑、三种我方单位、五种敌人和六波；锻骨通过塔升级产生实际收益，魔骨晶暂缓。
6. 加入叠波上限，防止故意留怪无限经营；将真正的大教团保留为剧情后续威胁。
